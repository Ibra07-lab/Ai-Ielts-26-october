### 2. Validation Architecture

**Main Validator** (`_validate_battle_consistency`)
- Routes questions to specific validators based on format
- Logs validation progress
- Comprehensive error handling

**Question-Specific Validators:**

#### A. `_validate_tfng_question()`
Checks:
- TRUE answers don't have negative language
- FALSE answers don't have confirming language
- NOT GIVEN answers don't claim contradiction/confirmation
- Auto-fixes contradictions

#### B. `_validate_mcq_question()`
Checks:
- Correct answer exists in options list
- Rationale explains why correct answer is RIGHT
- No negative language about correct answer
- Fixes mismatches automatically

#### C. `_validate_heading_question()`
Checks:
- Rationale explains main idea (not details)
- References "main idea", "paragraph", or "topic"
- Warns if focused on keyword matching
- Enhances rationales as needed

#### D. `_validate_completion_question()`
Checks:
- Answer exists verbatim in passage
- Word count respects limits (one word, two words, etc.)
- Grammar fits the gap
- Critical errors logged (can't auto-fix without changing meaning)

#### E. `_validate_short_answer_question()`
Checks:
- Answer is extractable from passage
- Rationale shows where answer is found
- Partial match detection for debugging
- Enhances rationales if needed

### 3. Helper Methods

**`_generate_mcq_rationale()`** - Generates consistent MCQ explanations
**`_generate_completion_rationale()`** - Generates completion explanations
**`_generate_consistent_rationale()`** - General fallback for T/F/NG

### 4. Improved Generation Prompts

#### A. Multiple Choice (`micro_battle_multiple_choice.txt`)
Added:
```
CRITICAL CONSISTENCY RULES:
- Correct answer MUST be one of the provided options (A, B, C, or D)
- Rationale MUST explain why correct answer is RIGHT
- NEVER write "Option X is incorrect" when X is the correct answer
- Quote passage evidence that supports correct answer
```

#### B. Short Answer (`micro_battle_short_answer.txt`)
Added:
```
CRITICAL WORD EXTRACTION RULES:
- Answer MUST be exact words from passage (no paraphrasing)
- Answer MUST respect word limit
- Answer MUST fit grammatically
- Hyphenated words count as ONE word
- Do NOT add words not in passage
```

#### C. Matching Headings (NEW: `micro_battle_matching_headings.txt`)
Created complete prompt with:
```
CRITICAL HEADING RULES:
- Each heading must represent MAIN IDEA, not a detail
- Heading should be more general than specific examples
- Rationale must explain what WHOLE paragraph is about
- Never match based on keyword matching alone
- First and last sentences usually contain main idea
```

## Validation Flow

```
Question Generated by LLM
    ↓
_validate_battle_consistency() called
    ↓
Routes to specific validator based on format:
  - true-false-not-given → _validate_tfng_question()
  - multiple-choice → _validate_mcq_question()
  - matching-headings → _validate_heading_question()
  - gap-fill/completion → _validate_completion_question()
  - short-answer → _validate_short_answer_question()
    ↓
Validator checks for inconsistencies
    ↓
If error found:
  - Log detailed error message
  - Auto-fix if possible
  - Log fix confirmation
    ↓
Question validated and ready for students
```

## Error Detection Examples

### Multiple Choice
❌ **Detected:** `correct_answer: "B"` but options only have A, C, D
✅ **Fixed:** Set to first available option, regenerate rationale

❌ **Detected:** Rationale says "Option B is wrong" when correct_answer is "B"
✅ **Fixed:** Regenerate rationale explaining why B is correct

### Matching Headings
⚠️ **Warning:** Rationale mentions "contains the keyword" (detail focus)
📝 **Action:** Log warning, suggest improving to focus on main idea

✅ **Enhancement:** Rationale doesn't mention "main idea"
📝 **Action:** Add main idea explanation to rationale

### Completion/Gap-fill
❌ **Critical:** Answer "renewable energy sources" not found in passage
🚨 **Action:** Log error, cannot auto-fix (would change meaning)

❌ **Detected:** Answer has 3 words but question says "NO MORE THAN TWO WORDS"
🚨 **Action:** Log critical error - would be marked wrong in real exam

### Short Answer
❌ **Detected:** Answer "solar panels" not in passage
🔍 **Action:** Check for partial matches, log if words found separately

✅ **Enhancement:** Rationale doesn't mention where answer is found
📝 **Action:** Add "The answer 'X' is found in the passage"

## Error Handling Strategy

### Auto-Fixable Errors (Silent Fix + Log)
- T/F/NG contradictory rationales
- MCQ answer not in options (use first option)
- MCQ negative language about correct answer
- Heading rationales without main idea mention
- Short answer rationales without location

### Warnings (Log + Suggest)
- Heading rationales focused on keywords
- Completion rationales without passage quotes

### Critical Errors (Log Only - Cannot Fix)
- Completion answers not in passage
- Short answer answers not extractable
- Word limit violations
- Answers would be marked wrong in real exam
